Typeferry receiver

Your phone as a PC keyboard and mouse.

This is the Windows program that the Typeferry phone app talks to over USB or Wi-Fi.

Download for Windows

Free, with no account. The fingerprint is on the release page.

Set it up

  1. Open the Typeferry app on your phone and start its setup guide.
  2. Open the receiver on your PC and leave its window open.
  3. Type the six digits the PC shows into the phone.
  4. Type the six digits the phone then shows into the PC window.

Good to know

It is not code signed yet, so Windows may warn you before it runs.

Where Windows blocks it, use the app's Bluetooth route, which needs no program.

It cannot type into administrator windows or before you sign in.

Support

Typeferry is free. A tip is welcome through Wise, which needs a Wise account.
